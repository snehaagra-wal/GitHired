## 📌 About GitHired

Traditional technical hiring is fundamentally flawed. Resumes are filled with buzzword inflation, tutorial clones, and unverifiable claims that waste hundreds of engineering hours on mismatched interviews.

**GitHired** transforms developer evaluation into an objective, empirical science. By analyzing real-world public GitHub repositories, GitHired deconstructs Abstract Syntax Trees (AST), evaluates modular architecture depth, tracks 52-week commit cadence, and provides deterministic engineering ratings and executive hiring dossiers in seconds.

## ✨ Core Feature Suite

### 1. 🔬 Algorithmic Code Complexity (AST Telemetry)
- Evaluates code hygiene, modular separation, and cyclomatic density across public repositories.
- Computes deterministic grades (**A+ to C**) across **Architectural Depth**, **Maintainability**, and **Ecosystem Impact**.
- Calculates star-to-fork ratios and authentic community influence.

### 2. 📅 52-Week Commit Cadence & Velocity Heatmap
- Visualizes daily contribution volume, longest active streaks, and release cadence over the last 365 days.
- Differentiates between authentic engineering velocity and artificial activity.

### 3. 🤖 Autonomous AI Talent Assistant (RAG Grounded)
- In-context AI assistant grounded strictly in the candidate's actual repositories.
- Includes **Candidate Q&A Mode** and **Technical Audit Mode**.
- Generates repository-specific, hard-hitting technical interview questions citing exact codebases.

### 4. ⚖️ Head-to-Head Developer Comparison
- Side-by-side benchmarking of two engineers simultaneously.
- Comparative radar charts for Velocity, Architecture, Ecosystem Impact, and Consistency.
- Autonomous hiring verdict recommending specific role fit for each engineer.

### 5. 🏆 Automated Skill Badges & Empirical Proofs
- Programmatically mints **Diamond**, **Platinum**, and **Gold** badges backed by real code volume.
- Zero resume inflation: every skill badge cites repository evidence and lines of code.

### 6. 📄 1-Click Executive PDF Talent Dossier
- Instant 1-click export of a confidential, dark-themed A4 talent dossier.
- Formatted with executive summary, key telemetry, verified competencies, flagship repositories, and interview strategies.
- Includes a **1-Click Copy Summary** button for quick sharing on Slack or Email.

### 7. 💫 Cyberpunk Motion Aesthetics
- **Moving Glowing Laser Border Beams**: High-end continuous glowing border beams (`@keyframes border-beam-spin`) circling the search input and feature capability cards.
- **Continuous Shifting Background Grid**: Smooth, infinite diagonal drifting matrix grid lines (`@keyframes panGrid`) behind the hero headline.
- **3D Network Highway Canvas**: Interactive perspective road canvas animating particles in real-time.

## 🛠️ Complete Tech Stack (प्रयुक्त टेक्नोलॉजी)

### Frontend & Core Architecture
- **[React 19](https://react.dev/)**: Latest concurrent rendering, component state management, and optimized hooks (`useState`, `useEffect`, `useRef`, `useCallback`).
- **[TypeScript 5.8](https://www.typescriptlang.org/)**: 100% strict type safety across all candidate dossiers, telemetry models, and API interfaces.
- **[Vite 8.3](https://vitejs.dev/)**: Next-generation frontend build tool with instantaneous Hot Module Replacement (HMR) and roll-up bundle optimization.

### Styling & Design System
- **[Tailwind CSS v4](https://tailwindcss.com/)**: Utility-first CSS framework tailored for modern glassmorphism, responsive grids, and flexible layouts.
- **Vanilla CSS3 Animations**: Custom `@keyframes border-beam-spin`, `@keyframes panGrid`, and conic gradients for 60fps moving laser beams and shifting background patterns.

- **[Framer Motion 13](https://www.framer.com/motion/)**: Smooth page transitions, word-by-word falling headline animations, scale hovers, and animated drawer panels.
- **HTML5 Canvas 2D/3D Context**: Custom procedural canvas animating an infinite drifting highway and floating ambient radar orbs.
- **[Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)**: Celebration particles for verified skill milestones and badge unboxing.

### PDF Generation & Document Export
- **[jsPDF 4.2](https://github.com/parallax/jsPDF)**: Direct programmatic generation of A4 executive PDF dossiers with custom dark themes, borders, and typography.
- **[html2canvas 1.4](https://html2canvas.hertzen.com/)**: High-fidelity DOM capture for document rendering.

### Icons & Assets

## 🚀 Quick Start & Installation

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm or yarn

### 1. Clone Repository
```bash
git clone https://github.com/snehaagra-wal/GitHired.git
cd GitHired
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Local Development Server
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 4. Build for Production
```bash
npm run build
npm run preview
```
